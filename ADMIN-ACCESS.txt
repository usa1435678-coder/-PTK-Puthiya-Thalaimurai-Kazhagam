PTK ADMIN DASHBOARD
===================

Local development:
  Start the website (npm install && npm start) then open:
  http://localhost:3000/admin/login

Live site:
  https://ptk-puthiya-thalaimurai-kazhagam.onrender.com/admin/login

First-run login:
  Username: admin
  Password: PTKadmin@2026

Notes:
  * If you set INITIAL_ADMIN_PASSWORD, that value is used as the password.
    Otherwise the documented default above is used (a legacy ADMIN_PASSWORD is
    only honored together with FORCE_ADMIN_RESET=true).
  * On the first run against an existing database the account is reset once to
    the default above so you are never locked out by an unknown password. After
    that, changes you make from the dashboard persist across restarts/redeploys.
  * To force a reset back to the configured/default password, set
    FORCE_ADMIN_RESET=true once and redeploy.
  * Change the initial password from Admin dashboard > System settings before
    using the site beyond testing. Keep your database and backups private.

Data & backups:
  * The SQLite database, automatic backups, uploaded files and the member CSV
    are stored on the persistent disk at /var/data (Render) or ./data locally.
  * A full snapshot is written automatically at every startup and before any
    destructive action. Data is never deleted by a redeploy.

Node.js is required. The default port is 3000.
