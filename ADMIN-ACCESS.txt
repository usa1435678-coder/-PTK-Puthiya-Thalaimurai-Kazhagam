PTK ADMIN DASHBOARD
===================

Local development:
  Start the website (npm install && npm start) then open:
  http://localhost:3000/admin/login

Live site:
  https://ptk-puthiya-thalaimurai-kazhagam.onrender.com/admin/login

First-run login:
  Username: admin
  Password: Set INITIAL_ADMIN_PASSWORD, or read data/admin-credentials.txt
           after first startup of a new local database.

Notes:
  * Existing administrator passwords are preserved when the app starts.
  * INITIAL_ADMIN_PASSWORD (or legacy ADMIN_PASSWORD) is used when creating an
    administrator; an existing account changes only when FORCE_ADMIN_RESET=true.
  * To force a reset, set a new INITIAL_ADMIN_PASSWORD of at least 12 characters
    and FORCE_ADMIN_RESET=true for one startup, then remove the reset flag.
  * Changing the password from Admin dashboard > System settings removes the
    generated first-run credentials file. Keep your database and backups private.

Data & backups:
  * The SQLite database, automatic backups, uploaded files and the member CSV
    are stored on the persistent disk at /var/data (Render) or ./data locally.
  * A full snapshot is written automatically at every startup and before any
    destructive action. Data is never deleted by a redeploy.

Node.js is required. The default port is 3000.
